# 04 — Catalog inspection

**What to build:** Add a read-only Catalog section to the Organization Inspection Workspace, allowing a Platform Administrator to inspect the Organization's Products, Categories, Add-Ons, and Product Add-On Attachments using Admin-like information presentation.

**Blocked by:** 01 — Inspection route shell and organization overview.

**Status:** ready-for-agent

- [ ] An active Owner User can browse and find Organization-scoped Products, Categories, Add-Ons, and attachment details from an Inspection URL.
- [ ] Catalog results expose useful historical and operational metadata while clearly handling no-data, loading, unavailable, and not-found states.
- [ ] The read model is Owner User guarded, preserves Organization scope, and Console exposes no catalog creation, editing, activation, or deletion controls.
