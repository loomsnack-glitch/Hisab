# Ganatri Admin and Ganatri POS are separate applications without legacy `/pos` routes

Ganatri Admin and Ganatri POS will be independent Turbo applications deployed at `admin.ganatri.in` and `pos.ganatri.in`: Admin owns Organization-administrator workflows, including read-only billing inspection, and POS owns Store Device workflows and all billing writes. The current `apps/web` application will become `apps/admin`, and a new `apps/pos` will own POS routes, layouts, and composition; reusable code will be extracted deliberately into workspace packages rather than copied between the applications. Each application will proxy its same-origin `/api` path to the shared backend, keeping browser cookies host-isolated without a cross-origin API contract. POS routes retain their current suffixes after dropping the `/pos` prefix, with its workspace at `/` and device login at `/login`. The existing Admin `/pos/*` URLs will be removed immediately rather than redirected, making the application boundary explicit and avoiding a permanent legacy routing contract. This supersedes the frontend “shared billing workspace” portion of ADR 0002, while retaining its isolated device-session and device-scoped API-route decisions.
