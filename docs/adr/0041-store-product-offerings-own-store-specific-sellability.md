# Store Product Offerings own store-specific sellability

Catalog Products remain Organization-owned reusable product definitions, and only the Organization catalog may create them. Every Catalog Product has exactly one Store Product Offering per Store in the Organization. Creating a Catalog Product writes an **active** Offering for each current Store, seeded from the create-form price and discount. Creating a Store writes an **inactive** Offering for each existing Catalog Product, seeded from the product's stored price and discount. Those two creation paths share an Organization-scoped transaction lock so a concurrent Product and Store creation cannot miss a pair. The Catalog Product's seeded commercial fields are immutable after creation; a Store Product Offering owns that Store's live selling price, discount, and active menu status. It cannot create a Store-private product definition, and it is never deleted. Availability is status only. This supports store-specific menus without copying product identities or making module ownership a per-Organization toggle.
